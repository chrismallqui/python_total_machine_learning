# Python para Data Science & Machine Learning en 18 días
Curso de "Python para Data Science & Machine Learning en 18 días" de Federico Garay. Data Science extremo con Numpy, Pandas, Matplotlib, Seaborn, Scikit Learn, Tensorflow, Machine Learning, y todo lo demás.

## Crear ENV de Miniconda
```bash
conda create --name python_total_machine_learning_env python=3.10
```

## Instalación de dependencias necesarias
```bash
pip install requests
pip install pandas
pip install matplotlib
pip install seaborn
```
